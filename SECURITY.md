# Security

This repository contains instructions for an AI assistant and two small scripts (`skills/build-studio/scripts/lint.sh`, `scripts/build_skill.py`). Neither script downloads or runs remote code.

If you find a rule that could lead the assistant to act unsafely (skip an approval, leak secrets, act on untrusted text, or test systems without permission), or a problem in the scripts, please report it privately through GitHub's "Report a vulnerability" option on this repository's Security tab instead of opening a public issue.
